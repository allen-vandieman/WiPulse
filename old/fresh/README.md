# Analize CSI data

## Analize pcap

```bash
# Usage: 
python read_pcap.py capture.pcap
```

## Analize csv

Reads CSV files generated by live_monitor.py --capture-mode complex

```bash
# Usage: 
python read_csv_csi.py csi_capture_*.csv
```

# Plot CSI

## Plot pcap

```bash
# usage 
py plot_csi.py captures\csi_capture.pcap
```

## Plot CSV

Creates the same plots as plot_csi.py but for CSV files

```bash
# usage: 
py plot_csv.py csi_capture_*.csv
```

## Motion plot

```bash
Usage: 
python motion_timeline.py csi_capture_*.csv
```
